# Contributing

Thanks for helping improve this unofficial NeoForge port.

## Bug reports

Please include:

- Minecraft version (expected: 1.21.1)
- NeoForge version (21.1.x)
- Java version (expected: JDK 21)
- Dual Hotbar port version
- Other installed mods, especially HUD, inventory, input, and keybinding mods
- Exact reproduction steps and expected/actual behavior
- Relevant `latest.log` or crash report, with personal information removed

## Changes

- Keep changes compatible with the project's GPL-3.0-only license.
- Preserve upstream attribution and existing license notices.
- Add or update tests/checklist items for behavior changes.
- Update `CHANGELOG.md` for user-visible changes.
- Do not commit generated `.gradle`, `.tools`, `build`, `run`, or IDE files.

By submitting a contribution, you agree that it may be distributed under this repository's GPL-3.0-only license. Do not submit code or assets that you do not have the right to contribute.
